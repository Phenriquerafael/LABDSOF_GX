Context map. Intervention Coordination is downstream (customer/supplier) of Issue Management. Issue offers an open host service (internal dispatch-context and membership API, §4.3) and a published language (event envelope and catalogue, §4.4). Dispatch publishes intervention events that Issue validates and projects. The calendar simulator is integrated through an anti-corruption layer (§4.5). One database per service; no shared tables; cross-context references are IDs only.
